# PPT 内容一致性与连贯播放实施计划

目标：画面表达 PPT 中已有的信息，按原页次序讲解，避免无依据的人物/场景和突变镜头。用户允许大幅修改并授权按计划执行。

现状证据：demo 第 1 页仅有年度新品发布和 AI 解决方案，却生成了无依据的手机硬件；第 2 页是四项能力，却生成了科幻人物。现有 Style Bible 统一了装饰风格，未建立事实到画面的约束。ScriptWriter 合并页面和轮换镜头进一步削弱页间逻辑。

方案：默认「忠实讲解」直接把源文字与原图制作成有信息层级的动画；不调用外部图像/视频生成。可选「AI 创意演绎」保留旧生成链路。选择确定性的内容表达作为高一致性保证，不能把提示词分数冒充视频语义验证。

架构边界：

- `faithful_plan.py`：提取逐页事实、布局类型、阅读时长、来源摘要和前后页承接；原页一一对应，不能重排/漏页/跨页合并。返回 EnhancedScenePlan。核对计划与当前 PPT 是否一致。
- `content_renderer.py`：原始事实卡片、明确流程、数据重点、图文版式；按内容顺序渐进呈现。固定镜头与位置系统，中文不截断，长内容分页；为配音/字幕预留位置，横竖屏均可用。
- `prompt_engine.py` / `main.py` / `gui.py`：增加 `visual_mode=faithful|creative`，默认 faithful；忠实模式无需视频生成 Key；UI 明确区分内容呈现方式与视频/界面风格。
- `video_composer.py`：统一时间轴，忠实模式拒绝无依据的生成片段；每页渲染实际来源，转场有前画面覆盖；输出可核对的内容与时间轴 JSON。
- `video_generator.py`：忠实计划禁止误走外部生成接口；旧创意链路仍可显式调用。

阶段与验收：

- [x] 对照原 PPT 与旧片抽帧；保存本轮逐文件 .bak、旧视频和旧 EXE。
- [x] 逐页事实计划及完整性检查：检测源文/数字篡改、页序或覆盖错误，不凭空构造流程或数据含义。
- [x] 内容动画：标题、要点、数据/流程、原图、长文本分页，横竖屏抽帧检查；保证文字和数字完整可读。
- [x] 入口和合成：默认忠实模式，无生成 API Key 可跑；原创意方式显式保留；语音、字幕、展示在同一时间轴；内容清单随片导出。
- [x] 实测 demo 全流程与复杂样例；段落衔接和边界抽帧；失败与旧链路回归；GUI 开关和真实工作流测试。
- [x] 交付新的 out.mp4 / 竖屏样例 / 新 EXE；检查普通用户可读权限；编写逐文件改动、命令、结果、限制和备份报告。
